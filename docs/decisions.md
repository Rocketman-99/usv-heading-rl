## D-004 대상 선박 — **OPEN, 작업자 결정 필요**

- 날짜:
- 상황: `nomotoParams.m` 에 문헌 출처가 확인된 세 세트가 등록되어 있다.
  프로젝트 제목은 USV(무인수상정)인데, K·T 가 1차 Nomoto 형태로 문헌에 직접
  제시된 세트는 대형 상선(Mariner 급 화물선, L = 160.93 m)이다.
  둘 사이의 불일치를 어떻게 처리할지 정해야 한다.
- 선택지:

  | | (a) `mariner` 유지 | (b) `otter` USV 로 교체 | (c) mariner 로 1단계, otter 로 2단계 |
  |---|---|---|---|
  | 계수 신뢰도 | 높음. Chislett & Strøm-Tejsen (1965) 실험 기반, 선형 미계수에서 재유도 검증 완료 | 낮음. T = 1 s 는 동정값이 아니라 MSS 오토파일럿 설계 가정값 | 1단계 높음 |
  | 제목 정합 | ✗ USV 가 아니라 화물선 | ✓ 실제 USV (Maritime Robotics Otter) | 최종적으로 ✓ |
  | 입력 형태 | ✓ 타각 δ (HANDOFF 정의와 일치) | ✗ 요 모멘트 τ_N. "러더 사용량" 지표 재정의 필요 | 재정의 필요 |
  | 시간 규모 | T = 107 s. 학습 1 에피소드가 길다 | T = 1 s. 학습이 빠르다 | |
  | 면접 리스크 | "왜 USV 라면서 화물선 계수인가?" | "T = 1 s 는 어디서 나온 값인가?" | 설명이 길어짐 |

- 결정:
- 근거:
- AI 활용:
- 재검토 시점:

> Claude Code 의견 (참고용, 결정 아님): (c) 를 권한다.
> 1단계는 계수 출처가 가장 단단한 `mariner` 로 파이프라인을 완주하고 —
> HANDOFF 9장의 "출처 없는 계수 사용 금지"를 확실히 지킬 수 있다 —
> 2단계에서 3자유도로 갈 때 대상을 USV 로 옮기면 제목과 내용이 맞는다.
> 다만 이 경우 1단계 문서에 "이 단계의 플랜트는 상선이며, 파이프라인 검증이
> 목적"이라고 명시해야 면접에서 방어된다.

  - (b) 제외 — HANDOFF 정의에 충실. 대신 "러더 사용량" 보상 항이 유일한 제약이 됨
  - (c) 1단계 검증은 제외, 학습은 포함
- 결정:
- 근거:
- AI 활용: 구현과 문헌값 확보는 위임, 포함 여부 판단은 직접
